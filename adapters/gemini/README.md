# Talyx Setup - Gemini Apps Gem

Copy all of [gemini-gem-instructions.txt](gemini-gem-instructions.txt) into your Gem and download [talyx-company-setup.md](talyx-company-setup.md) for its Knowledge. Follow the steps below.

## Create and use

1. In a computer browser, open `gemini.google.com` → open the sidebar → **Settings and help → Gems**. If **Gems** is already in the sidebar, select it directly. Choose **New Gem** and name it **Talyx Setup**.
2. Copy all the text from [gemini-gem-instructions.txt](gemini-gem-instructions.txt) into **Instructions**. Under **Knowledge → Add files → Upload files**, add the supplied `talyx-company-setup.md`, then **Save**.
3. Open **My Gems → Talyx Setup** and ask “Set up Talyx.” Answer its questions.
4. Save the provisional answer file. Download it if Gemini offers that; otherwise ask for the complete text and save it as a plain-text file named `talyx-company-setup.md`. In Gemini web, edit your private Gem, replace the old Knowledge file with the new one, and use the save action shown. Open a new chat with the Gem and check that it recalls the supplied answers. This does not prove that a local config was saved or that a workflow has used it.

On mobile, use the same account: **Menu → Gems → Talyx Setup**; if Gems is not listed yet, go to **Settings and help → Gems** first. Native Mac/Windows app Gem access is unverified; use the browser route if the app does not show Gems. Gems are not available in Gemini Live.

[Google: use Gems](https://support.google.com/gemini/answer/15146780?hl=en) · [Google: add files](https://support.google.com/gemini/answer/15235603?hl=en-GB)
